## Verification limits and required research

- Some catalog entries describe **recognized grammar topics** rather than one fully encoded operation. The reference URL may support the chapter broadly without individually validating every example of a subtype. The coding agent **must** verify unfamiliar lexical examples before encoding them as deterministic dictionary entries.
- The catalog does not claim that all literary variants are equally common or preferred in modern prose.
- Alternative writings may depend on the intended meaning, register and house style.
- Preserve example derivations as *attestation/lexicon targets*, not transformations for arbitrary word pairs.
- If a rule is marked `REVIEW`, or if evidence and expected output conflict, stop automatic suggestion and report the uncertainty.
- Project-specific Tamil IRV exceptions are user/editorial requirements, **not** statements sourced from the grammar pages.
- These sources are Tamil grammar references; no Bible text website was used.
